## 🎨 Design System Specifications

### Color Palette (18 Named Colors)

**Primary** — Dark theme foundation
- Ultra Dark: `#0f1219` (page background)
- Deep Navy: `#1a2f4d` (primary containers)
- Card BG: `#1f2937` (card backgrounds)
- Hover: `#2a3545` (hover states)

**Accent** — Premium highlights
- **Gold**: `#d4a574` (CTAs, highlights, emphasis)
- **Blue**: `#4a90e2` (secondary actions)
- **Success**: `#27ae60` (positive feedback)
- **Warning**: `#f39c12` (warnings)
- **Danger**: `#e74c3c` (errors)

**Text** — High contrast
- Primary: `#e8e8e8` (headlines, body)
- Secondary: `#9ca3af` (descriptions)
- Muted: `#6b7280` (disabled, helper)

### Typography System

**Fonts**
- Headings: Inter, sans-serif
- Body: Inter, sans-serif
- Code: Fira Code, monospace

**Sizes** (px)
- H1: 48px (bold)
- H2: 36px (semibold)
- H3: 28px (semibold)
- H4: 20px (semibold)
- Body: 16px (regular)
- Small: 14px (regular)
- Code: 14px (mono)

**Line Heights**: 1.2 - 1.6 (optimized for readability)

### Spacing Grid (8px-based)

- **Base unit**: 8px
- **Common values**: 8, 12, 16, 20, 24, 32, 40, 48, 56, 64, 72, 80, 96

### Shadow System

- **xs**: `0 1px 2px 0 rgba(0,0,0,0.05)` (subtle)
- **sm**: `0 1px 3px 0 rgba(0,0,0,0.1)` (light)
- **base**: `0 4px 6px -1px rgba(0,0,0,0.1)` (standard card)
- **md**: `0 10px 15px -3px rgba(0,0,0,0.1)` (medium)
- **lg**: `0 20px 25px -5px rgba(0,0,0,0.1)` (large)
- **card**: Custom (card default state)
- **card-hover**: Custom (card elevation)
- **gold-glow**: `0 0 20px rgba(212,165,116,0.3)` (accent)

## 🔧 Customization

**Colors**: Edit `tailwind.config.js` → `theme.extend.colors`

**Fonts**: Edit `tailwind.config.js` → `theme.extend.fontFamily`

**Spacing**: Edit `tailwind.config.js` → `theme.extend.spacing`

**Animations**: Add keyframes to `css/animations.css`

**New Components**: Add class to `css/components.css`
