  .card .card-base — Default

FORMS

STATUS

KEY PRINCIPLES TO REMEMBER
===========================

Executive Polish
  → Every pixel matters, nothing is cheap
  → Consistent, professional appearance
  → Premium spacing and typography

Dark Theme
  → Not pure black (#0f1219 instead of #000000)
  → Navy (#1a2f4d) for primary containers
  → High contrast text always

Gold Accents
  → #d4a574 for CTAs, highlights, emphasis
  → Pops beautifully against navy
  → Use sparingly for maximum impact

Smooth Animations
  → 200-300ms durations (optimal UX)
  → Smooth easing functions
  → Purposeful, not overdone

Responsive First
  → Mobile (320px) to Desktop (1400px+)
  → All layouts intentional at each breakpoint
  → No squeezed, responsive-breakage feeling

Accessible Always
  → High contrast (7:1 ratio)
  → Keyboard navigation throughout
  → Color + icons (not just color)
  → ARIA labels on interactive elements
